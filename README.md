# SwiftUI Elements Playground

An interactive catalog of every SwiftUI component, **with in‑code explanations** of why and how each element is used.

### What’s Inside
- **Core Layout**: VStack, HStack, ZStack, List, Form, Grid, ScrollView, Spacer, Divider  
- **Text & Labels**: Text styles, TextField, SecureField, Label, TextEditor, markdown  
- **Buttons & Controls**: Button, Toggle, Picker, DatePicker, Slider, Stepper, Menu  
- **Images & Media**: Image, AsyncImage, SF Symbols  
- **Navigation & Modals**: NavigationStack, TabView, Alert, Sheet, presentationDetents  
- **Data Passing**: @State, @Binding, @EnvironmentObject, passing values via NavigationLink  

### Learning Approach
Every file is fully commented directly in the code. Read the comments while you run the app – you’ll understand each keyword and element at a glance.
